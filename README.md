# Mac多窗口连点器 · MultiClick for macOS

[![MIT License](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)

原生 macOS 多窗口自动点击工具。为多个窗口分别设置点击位置、顺序、次数和间隔，在独立标签中管理并执行。

**要求：macOS 14 或更新版本。当前 DMG 为 Apple Silicon（arm64）版本。**

## 下载与安装

从 [Releases](https://github.com/wanderingsoulsdc/macos-multi-window-autoclicker/releases/latest) 下载 DMG，打开后将 **Mac多窗口连点器.app** 拖入 **Applications**。

当前公开包采用临时签名，未经过 Apple Developer ID 签名或公证，macOS 可能阻止直接打开；请自行评估下载来源，也可以按下方说明从源码构建。该版本不包含自动更新。

## 功能

- 一个窗口一个标签；独立保存点击方式、坐标、顺序、次数、间隔、轮数和循环设置。
- 多个后台任务同时执行，切换标签不打断运行；前台任务按顺序排队。
- 单独暂停、继续、停止，以及“全部暂停 / 继续、全部停止”。
- 屏幕取点、手动坐标、单次试点、点击点复制与排序、JSON 导入导出。
- 静态窗口预览，可缩放、滚动，预览和点击顺序支持上下 / 左右布局与拖动调节。
- 关闭主窗口后继续运行，通过菜单栏重新打开或退出整个程序。

## 第一次使用

1. 打开应用，在右侧点击“开启辅助功能权限”，按系统提示授权；刚授权后可退出并重新打开应用。
2. 从左侧选择目标窗口。已有窗口切回原标签，其他窗口创建独立标签；也可以选择“整个屏幕”。
3. 使用“屏幕取点”，或点击 `+` 手动添加点。取点覆盖层会拦截单击，不会点击到底下的应用；Esc 或右键取消。
4. 设置坐标、点击次数和每次点击后的等待时间；取消勾选的点不会执行。
5. 先用“单次试点”确认目标响应，再设置轮数或持续循环并开始任务。

**停止所有任务：Control + Command + Esc。全部暂停 / 继续：Control + Command + P。** 菜单栏和顶部也有全部控制，底部按钮只控制当前标签。

关闭主窗口只隐藏界面；从 Dock 或菜单栏可重新打开。菜单栏“退出程序”会停止所有任务、保存方案并退出。关闭运行中的标签会先询问，确认后停止并移除该标签的方案。

## 点击模式与限制

| 模式 | 行为 |
| --- | --- |
| 后台普通点击 | 尝试向指定窗口发送左键事件，尽量不移动鼠标或切换前台；目标软件可能忽略它 |
| 后台 Command 点击 | 带 Command 修饰键的后台事件，可能产生多选、打开新标签等不同含义，需自行确认 |
| 前台点击 | 使用系统鼠标，多个任务排队；轮到后在倒计时内手动将目标窗口置于前台，并保持点击位置无遮挡 |

屏幕模式仅支持前台点击。后台点击依赖非公开窗口坐标接口，**不能保证任意软件都支持，也不能保证后续 macOS 版本兼容**。应用不会自动切换到前台模式，也不会自动添加 Command 键或重试。

界面中的“已发送”仅表示事件已经发出，不代表目标软件已完成操作。更多说明见 [兼容性](docs/compatibility.md)。

## 坐标、预览与保存

窗口坐标以整个窗口左上角（包含标题栏）为 `(0, 0)`，单位为逻辑点。屏幕坐标以主显示器左上角为原点，多显示器允许负数。

窗口移动后跟随其位置；改变大小、关闭、隐藏、最小化或点失效时停止任务。改变大小后请刷新窗口列表并核对坐标。

“坐标画布”是位置示意图。可选的“截取窗口预览”需要屏幕录制权限，获取静态截图，内容变化后需重新截取。预览缩放不改变实际点击坐标。

全部标签方案保存在 `~/Library/Application Support/MacWindowClicker/workspace.json`，首次启动兼容读取旧版 `session.json`。重启后保留方案，但不会自动启动任务或沿用旧窗口编号，需要手动重新绑定。导入新增一个标签，导出当前标签方案。

应用在本地处理点击方案和截图，不内置网络上传或遥测。截图不写入方案文件。

## 从源码构建

安装提供 Swift 5.9 或更新工具链的 Xcode，以及对应的 macOS SDK。本项目无第三方 Swift 依赖。

```sh
git clone https://github.com/wanderingsoulsdc/macos-multi-window-autoclicker.git
cd macos-multi-window-autoclicker
swift test
zsh scripts/build-app.sh
```

生成的应用位于 `dist/Mac多窗口连点器.app`，也可双击根目录的 `打开Mac多窗口连点器.command`。构建脚本优先使用本机已有 Apple Development 签名身份，没有证书时使用临时签名；可用 `MAC_CLICKER_SIGN_IDENTITY` 指定身份。

制作公开 DMG（只处理应用副本，保留本地应用签名）：

```sh
zsh scripts/build-dmg.sh
```

当前处理器构建对应当前架构；Intel Mac 用户可以在支持的 Intel 开发环境中从源码构建，本项目尚未验证 Intel 发布包。公开 DMG 的临时签名不包含本地开发证书；其他人安装后需要独立授予权限。

## 项目结构与验证

- `Sources/ClickerCore`：方案、验证、坐标变换、持久化与前台队列。
- `Sources/MacWindowClicker`：SwiftUI 界面与 macOS 服务。
- `Tests/ClickerCoreTests`：核心自动测试。
- `Validation`：只针对自建测试窗口的验证工具，运行结果保留在忽略目录中。

核心测试与实际窗口验证的边界见 [测试说明](docs/testing.md)。个人方案、截图、运行记录、开发证书和构建产物不纳入源码仓库。安装包通过 GitHub Releases 单独提供。
