# 兼容性与权限

本项目面向 macOS 14+。发布包为 Apple Silicon arm64，未验证 Intel 二进制分发。

后台点击通过动态查找窗口坐标设置接口并向目标进程发送事件，涉及非公开接口。某些 AppKit 控件能接收后台事件，其他自绘控件可能只接收带 Command 修饰键的事件，还有软件会完全忽略后台点击。被遮挡不等于一定无法接收；最小化、隐藏、其他桌面空间和系统全屏状态不作可用性保证。

辅助功能 / 事件发送权限用于点击。可选的屏幕录制权限仅用于截取静态预览，拒绝截图权限不影响基本配置功能。重新构建或换用不同签名后，系统可能要求重新授权。

公开安装包采用 ad-hoc 临时签名，未使用 Developer ID 签名，也未公证；GitHub Release 中提供 SHA-256 校验文件。临时签名不等于 macOS 已信任发布者。

前台模式会占用鼠标。前台队列只串行管理本应用自己的任务，不能阻止其他软件或用户同时操作鼠标。窗口模式每次点击均检查目标进程身份、窗口位置与尺寸；尺寸变化时停止，避免沿用旧坐标。不会自动激活目标，也不会将后台任务静默改成前台。
